# POPULARS ARRAY METHOD USED IN JAVA

- Firstly Import <b>import java.util.Arrays;</b>


| Feature                 | Description                    | Example                          |
| ----------------------- | ------------------------------ | -------------------------------- |
| `arr.length`            | Length of the array            | `arr.length`                     |
| `Arrays.toString()`     | Print array as string          | `Arrays.toString(arr)`           |
| `Arrays.sort()`         | Sort array                     | `Arrays.sort(arr)`               |
| `Arrays.binarySearch()` | Find element (in sorted array) | `Arrays.binarySearch(arr, 3)`    |
| `Arrays.copyOf()`       | Copy array to new array        | `Arrays.copyOf(arr, 5)`          |
| `Arrays.copyOfRange()`  | Copy part of array             | `Arrays.copyOfRange(arr, 1, 3)`  |
| `Arrays.equals()`       | Compare two arrays             | `Arrays.equals(arr1, arr2)`      |
| `Arrays.fill()`         | Fill all elements with a value | `Arrays.fill(arr, 0)`            |
| `Arrays.setAll()`       | Fill array using lambda        | `Arrays.setAll(arr, i -> i * 2)` |
| `Arrays.stream()`       | Use Stream operations on array | `Arrays.stream(arr).sum()`       |
